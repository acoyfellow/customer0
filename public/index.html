  8. 08ghost

    Before an agent clicks, will the click land? A model that writes the rule beats a model that looks at the page.

    disproven Frozen eval, 193 real Browser Run pages labelled by a real click: one elementFromPoint call F1 0.883 for free; Workers AI llama-4-scout 0.662; SmolVLM-256M on WebGPU 0.349. A rule Fable 5.2 wrote from dev frames only tied the hand-written rule on every holdout page. Gym of 500 generated pages, scored on 5 unseen families: Fable's rule 0.737, the hand-written rule 0.647, Workers AI vision 0.444. It got 1.0 on an unseen mechanism, but missed the pre-registered 0.90 because some pages change after the agent looks.

    source · llms.txt · 2026-11-11
